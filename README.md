# K Explore – Responsive Event Management Website

A modern, responsive event platform built with **HTML5, CSS3 and vanilla JavaScript** for the K Explore Web Designing task.

## Features
- Hero section with a live countdown to the next event
- Event cards (name, date, venue, image, short description)
- Search by keyword and filter by category
- Event detail modal with registration form
- JavaScript validation (name, email, 10-digit phone, event) with inline errors and duplicate check
- Confirmation message after successful registration
- **Bonus:** dark/light mode (remembers choice), countdown timers, animations, and Local Storage registration management (view and cancel)
- Responsive for mobile, tablet and desktop; keyboard accessible; respects reduced-motion

## Run locally
Open `index.html` in a browser (no build step needed).

## Deploy
1. Push to GitHub: `git init && git add . && git commit -m "Initial commit" && git remote add origin <repo-url> && git push -u origin main`
2. Deploy free on **Netlify** (drag the folder), **Vercel**, or **GitHub Pages** (Settings → Pages → main branch).

## Structure
```
index.html   – markup
style.css    – theme variables, layout, responsive rules
script.js    – event data, rendering, filters, validation, localStorage, timers
```
